# Python Security Monitoring Lab

An educational Python project created to demonstrate concepts related to
keyboard monitoring and screen-capture technology in an authorized,
controlled cybersecurity laboratory environment.

## 🎯 Purpose

This project is intended for:

- Python learning
- Cybersecurity education
- Security awareness
- Authorized testing
- Understanding how monitoring techniques work
- Defensive security research

## ⚙️ Technologies

- Python 3
- MSS
- Requests
- Pynput
- Discord Webhooks
